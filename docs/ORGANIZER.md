# Инструкция для организаторов

1. Установите приложение «Регистрация гостей» с компьютера организатора (APK на Android или установка через Xcode / TestFlight на iPhone).
2. Откройте приложение и разрешите доступ к камере.
3. Выберите этап, на котором вы работаете.
4. Наведите камеру на QR-код на бейдже (или введите код вручную и нажмите **Найти**).
5. Проверьте ФИО гостя и нажмите **Зарегистрировать**.
6. Нажмите **Сканировать следующего** — выбранный этап сохранится.

Повторная отметка того же этапа не создаёт дубликат. Отмечается только выбранный этап.

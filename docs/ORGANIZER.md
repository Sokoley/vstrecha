# Инструкция для организаторов

1. Установите приложение «Регистрация гостей» с компьютера организатора (APK на Android или установка через Xcode / TestFlight на iPhone).
2. Откройте приложение и разрешите доступ к камере.
3. Наведите камеру на QR-код на бейдже.
4. Проверьте ФИО и статусы этапов.
5. Выберите этап и нажмите **Регистрация**.
6. Нажмите **Сканировать следующего**.

Если камера не работает — введите код с бейджа вручную и нажмите **Найти**.

Повторная отметка того же этапа не создаёт дубликат.
